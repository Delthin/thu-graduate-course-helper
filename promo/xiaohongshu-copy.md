## 可直接发布的正文

每次研究生选课都要在一长串列表里来回找课程、看时间、记课序，再单独打开报名统计页判断一二三志愿，真的很容易看乱。

所以我给清华研究生选课系统写了一个油猴脚本，把它改成了按「星期 × 大节」排列的可视化课程表。

现在可以直接在课程表里：

- ✅ 看课程时间和冲突
- ✅ 看报名总人数 / 可选容量
- ✅ 分开看第一、第二、第三志愿人数
- ✅ 查看优先报名人数
- ✅ 显示课程备注和教师
- ✅ 区分硕士生英语的论文阅读写作、国际学术交流、综合学术英语
- ✅ 直接勾选课序、设置志愿
- ✅ 每 3 分钟检查一次登录状态，尽量避免页面放久后掉登录

人数示例：

「总108/159｜一15｜二12｜三81」

这样就不只是看“总共有多少人”，还可以判断高志愿人数到底多不多，更方便决定哪门课放一志愿、二志愿或三志愿。

右上角课程表按钮还有一个状态点：绿色代表保活正常；橙色代表网络请求失败；红色代表登录已经过期，需要从信息门户重新进入。

脚本不会自动提交、退课或删除课程。只有自己点击“提交所选”并再次确认后，才会调用学校原来的选课表单。

项目已经整理成 Git 仓库，带完整 README、安装教程、自动测试和 MIT License：

https://github.com/Delthin/thu-graduate-course-helper

非官方工具，课程容量、报名人数和最终选课结果都以学校系统为准。

## 更短版本

把清华研究生选课列表改成课程表了！

可以直接看时间冲突、课程备注、总报名人数，以及一二三志愿和优先报名人数；还能在课程表里勾选课序、设置志愿。页面每 3 分钟检查一次登录状态，减少挂久后掉登录的问题。

脚本已整理成 Git 仓库，README、测试和 MIT License 都有。非官方工具，最终数据和选课结果以学校系统为准。

## 评论区置顶文案

安装方法已经写在 README 里：先安装 Tampermonkey，再粘贴 `.user.js` 保存，从清华信息门户的“应用导航 → 研究生选课”进入即可。脚本不会收集账号密码，也不会自动提交课程。
